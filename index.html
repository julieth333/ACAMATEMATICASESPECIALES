Modelo matemático

El circuito se modela con la ecuación diferencial de segundo orden (Ley de Voltajes de Kirchhoff) y se resuelve con la Transformada de Laplace. Con condiciones iniciales nulas y los valores R = 2 Ω, L = 0.5 H, C = 0.02 F, V₀ = 10 V:

vC″ + 4·vC′ + 100·vC = 1000·u(t)
VC(s) = 1000 / [ s·(s² + 4s + 100) ]
s = −α ± j·ωd = −2 ± j·4√6   (raíces complejas)
vC(t) = V₀·[ 1 − e−αt·( cos(ωdt) + (α/ωd)·sin(ωdt) ) ]
vC(t) = 10 − 10·e−2t·cos(4√6·t) − (5/√6)·e−2t·sin(4√6·t) [V]
i(t) = C·dvC/dt = (V₀/(ωd·L))·e−αt·sin(ωdt) = (5/√6)·e−2t·sin(4√6·t) [A]

La frecuencia natural es ω₀ = 1/√(LC) = 10 rad/s y el factor de amortiguamiento α = R/(2L) = 2 s⁻¹. Como la razón de amortiguamiento ζ = α/ω₀ = 0.2 < 1, el sistema es subamortiguado: oscila a ωd = √(ω₀² − α²) ≈ 9.80 rad/s y decae con constante de tiempo 1/α = 0.5 s.
